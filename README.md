# LexNova Consultoría Legal

Proyecto de portafolio desarrollado con **Next.js + TypeScript** para una firma ficticia de consultoría legal online.

## Incluye

- Diseño profesional y responsive.
- Next.js App Router + TypeScript.
- Servicios: civil, familia, laboral y empresas.
- Proceso de consulta, equipo, preguntas frecuentes y contacto.
- SEO básico.
- Exportación estática para GitHub Pages.
- Workflow de despliegue automático.

> LexNova es una marca ficticia utilizada únicamente como demostración de portafolio. Los textos no constituyen asesoría legal.
